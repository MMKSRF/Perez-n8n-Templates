🇪🇹 Ethio-Cinematic AI Video FactoryAn automated n8n workflow that generates spiritual, high-quality cinematic videos of Ethiopia. It combines Imagen 3 (Vertex AI) for visuals, Gemini 1.5 Flash for metadata, and MediaFX for video production.✨ FeaturesDeep Variety: Randomly generates from 500+ combinations of Ethiopian spiritual themes, artistic styles, and sacred Ge'ez quotes.Authentic Ge'ez Support: Automatically integrates Amharic text into video descriptions and image prompts.Multi-Platform Ready: Designed for YouTube Shorts (9:16) with automated title and description generation.Audio-Initiated (Optional): Trigger a video generation by sending a voice message to a Telegram Bot.🚀 How It WorksRandomizer (JS): Selects a spiritual theme, a specific visual scene, and a random Amharic quote.Visual Engine (Vertex AI): Uses Imagen 3 to generate a hyper-realistic 9:16 image based on the selected theme.Metadata Engine (Gemini): Generates a viral YouTube title and a dual-language (Amharic/English) description.Production (MediaFX): Converts the static image into a moving cinematic video.Distribution (YouTube): Uploads the final video to your channel as a Private/Public Short.🛠 Setup & APIsTo run this workflow, you will need the following API credentials:ServiceAPI RequiredWhere to get itGoogle CloudVertex AI API & YouTube Data API v3Google Cloud ConsoleTelegramTelegram Bot Token@BotFathern8nSelf-hosted or Cloud instancen8n.io1.
